# OSGate 1.0 — критерии приёмки

## Принимаемый объём релиза
- Рабочий SOCKS5 CONNECT только через проверенный SSH direct-tcpip, без локального fallback.
- Администрирование SSH-серверов и SOCKS5-клиентов, включая изменение паролей.
- Проверка реального SSH и маршрута в интернет, автоматическое восстановление после потери соединения.
- Настройки health/reconnect, журнал, диагностика, суммарная статистика.
- SQLite/Alembic с сохранением при перезапуске.
- Docker, Compose, systemd, CLI и инструкции.
- Авторизация, IP-ограничения, проверка SSH host keys, CSRF и отзыв сессий.
- Автоматические тесты, сборка Docker и интеграционный E2E с реальным OpenSSH.

## Согласованные исключения
По решению владельца репозитория испытания на двух физических SSH-серверах и нагрузочные тесты не являются обязательными условиями релиза. Их отсутствие не следует выдавать за пройденные тесты.

## Правило выпуска
Тег 1.0.0 и публикация образа latest — только после выполнения и проверки кода, успешного CI и финального merge.
